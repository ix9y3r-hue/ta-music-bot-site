# T&A Music Bot Website

موقع عربي تعريفي لبوت T&A الموسيقي على Discord، مبني بملف HTML مستقل ويُستضاف مجانًا عبر GitHub Pages.

## النشر
من المستودع افتح Settings ثم Pages، واختر Deploy from a branch، ثم branch `main` والمجلد `/(root)` واضغط Save.

رابط دعوة البوت الموجود في الموقع يستخدم معرّف التطبيق `1390140608915574815`.
